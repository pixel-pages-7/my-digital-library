# 📚 Digital Library Web App

A clean, responsive, and feature-rich Web Application designed to showcase and manage a personal collection of classic books. Built with pure HTML, CSS, and JavaScript.

---

## ✨ Features

* 🎨 **Modern & Responsive UI**: Stylish card layout with dark mode support.
* 🌙 **Dark Mode Toggle**: Easily switch between Light and Dark themes.
* 📈 **Live Statistics Dashboard**: Real-time counter for Total Books, Favorite Books, and Read Books.
* 🔍 **Search & Genre Filter**: Search books by title/author or filter them by genre (Dystopian, Political Satire, Classic Fiction).
* 📄 **Page Sorting**: Sort books dynamically based on page count.
* ➕ **Add New Books**: Interactive form to add custom books with custom quotes, ratings, and image links.
* 📖 **Read Status & Favorites**: Mark books as Read/Unread and save your favorite classics.
* 💬 **Quote Pop-up (Modal)**: Click "Read More" to open an animated pop-up displaying quotes and descriptions.
* 💾 **LocalStorage Integration**: All updates, newly added books, and read states are saved in the browser!

---

## 🛠️ Tech Stack

* **HTML5**: Semantic structure.
* **CSS3**: Custom styling, Flexbox layout, CSS variables, and dark mode transitions.
* **JavaScript (ES6+)**: DOM manipulation, event handling, data filtering/sorting, and LocalStorage integration.

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
3. Enjoy managing your library!
